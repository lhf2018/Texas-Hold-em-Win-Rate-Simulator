# 德扑模拟

采用赌场风格的本地德州扑克练习游戏。一名真人玩家对阵 1～9 名电脑，可随时开启或关闭实时胜率分析。

## 启动

```powershell
pip install -r requirements.txt
python app.py
```

打开 [德扑模拟](http://localhost:5000/)。无需配置第三方服务或 API Key。

## 开桌设置

点击「入座并开始」或「重新开桌」，可选择：

| 设置 | 范围或默认值 |
| --- | --- |
| 牌桌人数 | 2～10 人，包含你和 1～9 名电脑；默认 4 人 |
| 每人起始筹码 | 100～100,000 点的整数；默认 1,000 点 |
| 快捷筹码 | 500、1,000、2,000、5,000 点 |
| 盲注 | 小盲 10、大盲 20，固定不随起始筹码变化 |

确认后开始牌局。重新开桌会重置当前牌局、筹码及行动记录。页面显示当前人数、在桌人数和开桌筹码。

## 玩法

- 电脑按顺序行动，轮到你时选择弃牌、过牌、跟注或加注。操作按钮位于你的玩家信息旁边。
- 默认规则：每个下注轮每位玩家最多主动下注或加注一次（盲注不占次数，全下加注占一次）。按该轮初始顺序，最后一位玩家仍可加注；如果他加注，后续补充行动只能跟注或弃牌，无论其他人是否用过加注机会。进入下一下注轮重置。首轮行动结束即封口，末位仅跟注也不例外。
- 「本轮加注到」输入的是**本轮下注总额**。可用半底池、底池、全下或底部的 10、20、50、100、200 快捷键填入金额，再点击「加注」或「全下」确认。
- 支持翻牌前、翻牌、转牌、河牌、全下自动发完公共牌、主池/边池结算、平分底池和庄家轮转。
- 每手结束后，「发下一手」会在牌桌中央、公共牌下方弹出。玩家筹码耗尽后离桌，剩两人时使用单挑盲注规则。你出局或只剩一人时，浮层改为「重新开桌」。
- 对手底牌只在未弃牌的摊牌结算时展示。弃牌者底牌继续隐藏。
- 页面刷新可恢复当前服务进程中的牌局；服务重启后需要重新开桌。

## 牌桌与交互

- 牌桌采用绿绒台面、软包围栏、金色下注线和酒红色牌背，玩家沿桌外排列。
- 开局时五张公共牌扣在桌面上。翻牌圈的三张牌依次原地翻开，转牌和河牌各自翻开。全下时，余下的公共牌依次翻开。
- 宽屏时自己的座位对准牌桌中线。手牌框和操作框底边齐平，三个操作按钮等宽，并与下方的数字快捷键左右对齐。
- 整页按窗口大小适配到一屏；较长分析和行动记录在各自面板内滚动。
- 轮到决策的座位显示金色高亮和「决策中」标签。
- 最新行动在座位旁显示彩色标签，行动记录中的最新一条同步高亮。
- 玩家框外显示蓝色 **小盲 10** 或金色 **大盲 20**，每手随庄家轮转。
- 每位玩家本手的累计投入在其面前的桌面上显示为图形筹码堆，包含盲注，金额随下注更新。不同颜色表示不同面额，较多筹码采用压缩堆叠展示，旁边数字表示累计总额。结算后清空。
- 玩家信息框旁另有绿色小筹码标识，显示「本轮」累计投入，包含本轮盲注、跟注和加注；切换到下一下注轮时归零。弃牌后保留本轮已投入数额，本手结算后隐藏。
- 赢家座位显示金色光效、粒子和「获胜 +筹码」，同时播放底池筹码飞向赢家的动画。多人分池分别展示；提示金额为本手分得的筹码，不是净盈利。
- 结算显示在本手记录上方，按主池、边池和未被跟注的退回金额列出，并显示自己的分得筹码和净收益。点击各池可切换赢家及最佳五张高亮。
- 系统开启减少动态效果偏好时，公共牌直接显示牌面，赢家仍有静态标识。

## 可选实时分析

实时分析开关默认关闭，关闭时页面不会调用分析接口，游戏照常进行。偏好保存在当前浏览器。开启后，仅在轮到你行动时，自动计算本次决策的独赢概率、平局概率、底池权益、跟注EV和听牌概率。

**严格以你的视角分析：**

1. 服务端游戏引擎保存真实底牌和未发牌堆；客户端只得到自己的两张牌、已发公共牌、公开筹码与行动记录。
2. 分析器仅接收公开快照，完全不接收牌局对象和未发牌序列，也不读取快照里的对手底牌字段。
3. 使用公开的过牌、跟注、加注/全下及下注金额相对底池的大小，为对手候选手牌加权。没有自愿下注记录时使用随机范围。
4. 仅排除你已知的牌，从未知牌中抽取互不重复的对手手牌，再随机补齐公共牌。模拟不会排除服务器实际发给其他人的牌，因为你不知道这些牌。
5. 每次 2,500 次抽样，结果会有统计波动；下注范围是启发式推测，允许弱牌、慢打和诈唬，并非已知对手策略的精确解。

底池权益包含多人平分底池的份额。跟注EV按当前公开投入及你本次跟注后的主池/边池资格计算，假设此后不再额外下注、无抽水。未来行动、未来投入与弃牌收益没有建模，不能直接用来判断加注价值。听牌成牌概率不等于获胜概率。

电脑也只用自己的底牌和公共牌进行独立估算，不读取其他玩家底牌。电脑不是GTO策略机器人。

## 电脑打牌风格

开桌时，每位电脑随机形成偏紧、偏松、激进、爱跟注或均衡的一类风格，并在松紧程度、主动性、诈唬倾向及下注大小上产生小幅个体差异。同名电脑在重新开桌后可能换一种风格，点击「发下一手」则保持原有风格。

风格影响起手牌选择和相近收益行动的混合权重；下注从合法候选尺寸中选取，避免因为随机尺寸产生巨大偏差。电脑还会参考底池赔率、跟注占剩余筹码的比例、牌局阶段和对手人数。风格属于内部策略，不在座位上直接标注，玩家可通过多手观察判断。新版使用公开行动学习对手频率，并比较候选行动收益；仍属于启发式策略，不是完整策略求解器。

## 文件

- `app.py`：Flask页面、会话牌桌API，以及兼容的独立计算接口。
- `game.py`：发牌、合法行动、下注轮、全下、边池与结算。
- `bots.py`：性格、新版收益决策与旧版评测基线。
- `ranges.py`：共享公开行动范围与互斥牌张采样。
- `benchmark.py`：固定种子交换座位评测。
- `poker.py`：最佳五张牌判定、蒙特卡洛及听牌计算。
- `analysis.py`：仅依赖公开信息的对手范围与决策分析。
- `templates/index.html`、`static/game.css`、`static/game.js`：游戏页面。
- `test_app.py`、`test_game.py`、`test_bots.py`：算法、牌局和电脑风格测试。

```powershell
python -m unittest -v
```

自动化测试覆盖：

- 全部牌型、踢脚牌，以及 3,000 组随机七张牌与最佳五张组合的对照。
- 盲注行动顺序、单挑、全下发完公共牌、主池与边池分配。

## 运行边界

牌桌保存在单进程内存中，服务重启后需要重新开桌；闲置超过两小时的牌桌可能被清理。开发服务器仅监听本机，不提供多人联网、持久化账号或真实货币功能。无需第三方AI服务或API Key。


## 范围与收益策略升级

全桌统一使用首轮可加注、补充行动仅跟齐或弃牌的规则，不提供模式选择。电脑只接收自身手牌和公开信息，根据最近四次行动、位置、金额以及带先验的入池率、翻牌前加注率、面对下注弃牌率加权范围；统计在同一张桌跨手保留，重新开桌清空。

新版逐项比较弃牌、跟注/过牌、三分之一/三分之二/满池及全下。收益模拟计入对手弃牌、跟注金额、有效筹码和边池；非河牌使用位置与筹码底池比的权益实现折扣，翻牌前使用位置、人数、有效筹码调整起手牌选择。弃牌反应、范围、未来成本都是近似模型，未实现多轮博弈求解或标准起手牌表。

决策至少128、最多768个有效样本，每64个检查收益差距及约350毫秒软预算（范围构建和最小批次可能超时）。风格只在接近最优收益的行动间混合。每手结束后展开“电脑决策复盘”，查看当时权益、范围说明、候选收益及抽样误差；进行中不公开电脑估计，避免暴露策略信息。玩家分析展示2500次抽样及95%保守误差界，误差不包含模型偏差。

运行固定种子、交换座位的单挑对照评测：

```powershell
python benchmark.py --pairs 100 --seed 42
```

输出新版相对旧版的每百手大盲收益和按配对牌局计算的近似95%区间。每手重置筹码，评测关闭时间早停以保证复现；当前评测不代表多人桌或长期对手学习效果，不能仅凭少量牌局认定新版更强。


### 自定义加注规则修订

每个下注轮先按顺序行动一遍，每个人在这次行动时可加注到高于当前最高下注的整数金额（不要求翻倍），或跟齐/过牌/弃牌。第一遍结束后，尚未跟齐的人只补齐最高下注或弃牌；即使之前未加注，也不能在补充行动中加注。下一下注轮重新开放。
