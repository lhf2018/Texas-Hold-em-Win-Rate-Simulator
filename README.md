# 德扑模拟

保留深绿牌桌、暖金按钮和圆角卡片风格的本地德州扑克练习游戏。一名真人玩家对1至9名电脑，胜率分析是可随时开关的辅助能力。

## 启动

```powershell
pip install -r requirements.txt
python app.py
```

打开 [德扑模拟](http://localhost:5000/)。无需配置第三方服务或 API Key。

## 开桌设置

点击「入座并开始」或「重新开桌」，可选择：

| 设置 | 范围或默认值 |
| --- | --- |
| 牌桌人数 | 2～10 人，包含你和 1～9 名电脑；默认 4 人 |
| 每人起始筹码 | 100～100,000 点的整数；默认 1,000 点 |
| 快捷筹码 | 500、1,000、2,000、5,000 点 |
| 盲注 | 小盲 10、大盲 20，固定不随起始筹码变化 |

确认后开始牌局。重新开桌会重置当前牌局、筹码及行动记录。页面显示当前人数、在桌人数和开桌筹码。

## 玩法

- 电脑按顺序行动，轮到你时选择弃牌、过牌、跟注或加注。操作按钮位于你的玩家信息旁边。
- 每个下注轮（翻牌前、翻牌、转牌、河牌）全桌最多一次主动下注或加注，盲注不占次数，全下加注也占一次。机会使用后，其他玩家只能跟注、过牌或弃牌；进入下一轮重新开放。此为练习桌的自定义规则。
- 加注输入的是**本轮下注总额**；可快速选择半底池、底池或全下金额，再点击「加注」确认。
- 支持翻牌前、翻牌、转牌、河牌、全下自动发完公共牌、主池/边池结算、平分底池和庄家轮转。
- 玩家筹码耗尽后离桌，剩两人时使用单挑盲注规则。你出局或只剩一人时可重新开桌。
- 对手底牌只在未弃牌的摊牌结算时展示。弃牌者底牌继续隐藏。
- 页面刷新可恢复当前服务进程中的牌局；服务重启后需要重新开桌。

## 牌桌与交互

- 横向圆角长方形牌桌，玩家沿桌外排列；玩家框统一圆角，同排、同列对齐。
- 整页按窗口大小适配到一屏；较长分析和行动记录在各自面板内滚动。
- 轮到决策的座位显示金色高亮和「决策中」标签。
- 最新行动在座位旁显示彩色标签，行动记录中的最新一条同步高亮。
- 小盲显示蓝色 **SB · 小盲 10** 标识，大盲显示金色 **BB · 大盲 20** 标识；每手随庄家轮转。
- 每位玩家本手的累计投入在其面前的桌面上显示为图形筹码堆，包含盲注，金额随下注更新。不同颜色表示不同面额，较多筹码采用压缩堆叠展示，旁边数字表示累计总额。结算后清空。
- 赢家座位显示金色光效、粒子和「获胜 +筹码」，同时播放底池筹码飞向赢家的动画。多人分池分别展示；提示金额为本手分得的筹码，不是净盈利。
- 结算不弹出「本手结算」浮层；通过赢家标识查看结果，再点击「发下一手」继续。
- 系统开启减少动态效果偏好时，取消庆祝动画，保留静态赢家标识。

## 可选实时分析

实时分析开关默认关闭，关闭时页面不会调用分析接口，游戏照常进行。偏好保存在当前浏览器。开启后，仅在轮到你行动时，自动计算本次决策的独赢概率、平局概率、底池权益、跟注EV和听牌概率。

**严格以你的视角分析：**

1. 服务端游戏引擎保存真实底牌和未发牌堆；客户端只得到自己的两张牌、已发公共牌、公开筹码与行动记录。
2. 分析器仅接收公开快照，完全不接收牌局对象和未发牌序列，也不读取快照里的对手底牌字段。
3. 使用公开的过牌、跟注、加注/全下及下注金额相对底池的大小，为对手候选手牌加权。没有自愿下注记录时使用随机范围。
4. 仅排除你已知的牌，从未知牌中抽取互不重复的对手手牌，再随机补齐公共牌。模拟不会排除服务器实际发给其他人的牌，因为你不知道这些牌。
5. 每次 2,500 次抽样，结果会有统计波动；下注范围是启发式推测，允许弱牌、慢打和诈唬，并非已知对手策略的精确解。

底池权益包含多人平分底池的份额。跟注EV按当前公开投入及你本次跟注后的主池/边池资格计算，假设此后不再额外下注、无抽水。未来行动、未来投入与弃牌收益没有建模，不能直接用来判断加注价值。听牌成牌概率不等于获胜概率。

电脑也只用自己的底牌和公共牌进行独立估算，不读取其他玩家底牌。电脑不是GTO策略机器人。

## 文件

- `app.py`：Flask页面、会话牌桌API，以及兼容的独立计算接口。
- `game.py`：发牌、合法行动、下注轮、全下、边池与结算。
- `poker.py`：最佳五张牌判定、蒙特卡洛及听牌计算。
- `analysis.py`：仅依赖公开信息的对手范围与决策分析。
- `templates/index.html`、`static/game.css`、`static/game.js`：游戏页面。
- `test_app.py`、`test_game.py`：算法与牌局测试。

## 验证

```powershell
python -m unittest -v
```

自动化测试覆盖：

- 全部牌型、踢脚牌，以及 3,000 组随机七张牌与最佳五张组合的对照。
- 盲注行动顺序、单挑、全下发完公共牌、主池与边池分配。
- 每轮单次加注限制、短码全下占用次数及新一轮重置。
- 2～10 人完整牌局、自定义起始筹码、筹码守恒及非法配置拒绝。
- 会话隔离、过期行动拒绝，以及更换隐藏底牌或牌堆后公开信息分析保持不变。

这些测试验证后端规则和分析逻辑；座位布局、筹码图形和动画需在浏览器中检查。

## 运行边界

牌桌保存在单进程内存中，服务重启后需要重新开桌；闲置超过两小时的牌桌可能被清理。开发服务器仅监听本机，不提供多人联网、持久化账号或真实货币功能。无需第三方AI服务或API Key。
