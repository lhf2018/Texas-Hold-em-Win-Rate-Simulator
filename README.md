# 德扑胜率模拟器 - 使用文档

## 📖 项目简介

德扑胜率模拟器是一款专业的德州扑克辅助工具，结合**蒙特卡洛算法**和**DeepSeek大模型AI**，帮助玩家在真实牌局中快速计算胜率、分析牌型、评估决策价值。

### ✨ 核心功能

- **🎯 蒙特卡洛模拟**：10,000次随机模拟，准确计算胜率、平局率、输率
- **🃏 智能牌型识别**：自动识别从皇家同花顺到高牌的所有牌型
- **🎲 听牌潜力分析**：计算同花听牌、顺子听牌的Outs和成牌概率
- **💰 底池赔率计算**：进阶模式下自动计算底池赔率
- **📊 期望价值(EV)**：量化决策，给出跟注/加注/弃牌建议
- **🤖 AI复盘分析**：接入DeepSeek大模型，生成专业策略建议


5. **访问应用**
打开浏览器访问：`http://localhost:5000`

## 📱 使用指南

### 1. 选择模式

| 模式 | 适用场景 | 功能 |
|:---|:---|:---|
| **基础模式** | 快速了解手牌强度 | 胜率 + 牌型分析 + 听牌潜力 |
| **进阶模式** | 真实牌局决策 | 基础功能 + 底池赔率 + EV + 行动建议 |

### 2. 输入手牌

- 点击两张手牌卡片区域
- 在弹出的牌面选择器中点击选择牌面
- 系统自动避免选择重复牌

### 3. 输入公共牌 ⚠️

**重要规则：必须按顺序填写！**

- **翻牌圈**：先填写前3张公共牌（位置①、②、③）
- **转牌圈**：填写第4张公共牌（位置④）
- **河牌圈**：填写第5张公共牌（位置⑤）

> 💡 **提示**：系统会强制顺序，无法跳过前面的牌直接填写后面的牌。不满足顺序时卡片会显示半透明且无法点击。

**辅助按钮**：
- `📌 翻牌圈`：提示填写前3张
- `🔄 转牌圈`：提示填写第4张
- `🌊 河牌圈`：提示填写第5张
- `🗑️ 清空公共牌`：一键清空所有公共牌

### 4. 配置参数

#### 基础模式
- **对手人数**：牌桌上除自己外的玩家数量（1-8人）

#### 进阶模式
- **底池大小**：当前底池总额（单位：BB）
- **需跟注金额**：要留在牌局需支付的筹码（单位：BB）
- **对手行动**：录入每个对手的实际行动（弃牌/跟注/加注/All-in）

### 5. 计算结果

点击 **「🧮 计算胜率」** 后，系统会显示：

#### 基础结果
- 胜率/平局率/输率（进度条可视化）
- 当前牌型（如：顶对K）+ 强度评价
- 听牌潜力（同花听牌、顺子听牌等）
- Outs数量和成牌概率

#### 进阶模式额外结果
- 底池赔率
- 期望价值(EV)
- 行动建议（跟注/加注/弃牌）

### 6. AI分析

点击 **「🤖 AI分析」** 按钮，DeepSeek大模型会基于当前牌局生成：

- 当前牌局评估
- 具体行动建议
- 风险评估

> ⚠️ **注意**：需要先配置 `DEEPSEEK_API_KEY` 环境变量

## 🧮 算法说明

### 蒙特卡洛模拟
- **模拟次数**：10,000次
- **原理**：根据已知牌随机补全公共牌和对手手牌，统计胜负平次数
- **响应时间**：< 2秒

### 牌型判定规则
| 牌型 | 等级 | 说明 |
|:---|:---:|:---|
| 皇家同花顺 | 1 | A-K-Q-J-10 同花 |
| 同花顺 | 2 | 任意5张连续同花 |
| 四条 | 3 | 四张相同点数 |
| 葫芦 | 4 | 三条 + 一对 |
| 同花 | 5 | 五张同花色 |
| 顺子 | 6 | 五张连续点数 |
| 三条 | 7 | 三张相同点数 |
| 两对 | 8 | 两个不同的对子 |
| 一对 | 9 | 一个对子 |
| 高牌 | 10 | 无任何成牌 |

### Outs计算
- **同花听牌**：13 - 已出现的同花牌数
- **两端顺听牌**：8张
- **卡顺听牌**：4张
- **成牌概率**：Outs × 4%（翻牌圈）或 Outs × 2%（转牌圈）

### 期望价值(EV)
```
EV = 胜率 × (底池 + 跟注金额) - 输率 × 跟注金额
```

- **EV > 0**：正期望价值，长期有利
- **EV < 0**：负期望价值，长期亏损

## ❓ 常见问题

### Q1: 胜率计算结果波动较大？
**A**: 蒙特卡洛模拟存在统计学波动，建议：
- 多次计算取平均值
- 关注胜率趋势而非单次数值
- 翻牌前波动约±5-8%，河牌圈波动约±1-2%

### Q2: 为什么不能直接填写第4张公共牌？
**A**: 德州扑克规则要求按顺序发牌：翻牌(3张) → 转牌(1张) → 河牌(1张)。系统强制顺序是为了模拟真实牌局，避免逻辑错误。

### Q3: AI分析提示"请设置API Key"？
**A**: 需要配置环境变量：
```bash
export DEEPSEEK_API_KEY="your-key-here"
```
然后重启Flask服务。

### Q4: 公共牌已填满但胜率显示为"--"？
**A**: 请确认已选择两张手牌，手牌未选满时无法计算。

### Q5: 进阶模式对手行动怎么填？
**A**: 根据真实牌局中每个对手的实际行动填写：
- **弃牌**：该玩家已弃牌，不需要填金额
- **跟注**：填写跟注金额
- **加注**：填写加注后的总金额
- **All-in**：填写All-in金额
